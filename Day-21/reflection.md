# Day 21 Reflection - Forbidden Functions Tournament

## What I Learned

Day 21 challenged me to solve problems without relying on common
built-in helper functions.

The challenge helped me understand the importance of fundamental
programming logic.

## Puzzle 1 - Recursion

I implemented factorial using recursion.

The function keeps reducing the problem:

factorial(n) = n * factorial(n - 1)

The recursion stops when n reaches 0 or 1.

This helped me understand base cases and recursive calls more clearly.

## Puzzle 2 - Stack

I implemented string reversal using a stack.

Each character is pushed into the stack.

Because a stack follows LIFO (Last In, First Out), popping the
characters produces the string in reverse order.

## Biggest Challenge

The biggest challenge was avoiding built-in shortcuts and thinking
about how the operations work internally.

## Key Realization

Built-in functions are useful in real software, but understanding
the underlying logic is important for debugging, interviews, and
algorithm design.

## Complexity

Recursive factorial:

Time: O(N)
Space: O(N)

Stack-based string reversal:

Time: O(N)
Space: O(N)

## Overall Learning

This challenge strengthened my understanding of recursion, stacks,
loops, and fundamental problem-solving techniques.
