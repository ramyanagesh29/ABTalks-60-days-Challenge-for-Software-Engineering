# Day 21 - The Forbidden Functions Tournament

## Objective

Solve two coding problems while avoiding built-in helper functions
such as:

- sort()
- sum()
- max()
- min()

## Puzzle 1 - Recursive Factorial

The factorial problem was solved using recursion.

Example:

5! = 5 × 4 × 3 × 2 × 1 = 120

The recursive function uses 0 and 1 as base cases.

### Complexity

Time: O(N)

Space: O(N)

## Puzzle 2 - Stack String Reversal

The string reversal problem was solved using a stack.

Characters are pushed onto the stack and then popped one by one.

Because stacks follow LIFO (Last In, First Out), the resulting
characters form the reversed string.

### Complexity

Time: O(N)

Space: O(N)

## Forbidden Functions

The solutions do not use:

sort()
sum()
max()
min()

## Key Learning

The challenge demonstrated why understanding fundamental algorithms
is important even when programming languages provide convenient
built-in functions.

Removing shortcuts forces us to understand the underlying logic.
