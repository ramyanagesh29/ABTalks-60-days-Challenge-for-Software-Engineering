# Day 8 – Understanding Arrays Through Real Data

## What My Program Does

This program uses a list of numbers to simulate user data. It checks each number and identifies whether it is an even number.

The program:

1. Loops through each number using a `for` loop.
2. Checks whether the number is divisible by 2 using the modulo (`%`) operator.
3. If the remainder is 0, the number is even. The program prints that number and increases the count by 1.
4. After checking all the numbers, the program prints the total number of even values.

## How Arrays Are Used in Real Systems

Arrays or lists are used to store multiple related pieces of data in sequence. They make it easier to process many values without creating separate variables for every value.

For example, real-world systems use arrays or lists in analytics dashboards, user activity tracking, log processing, and banking systems. A system can store and process data in sequence, such as customer records, queue information, daily visitors, or transaction data.

Using arrays makes it easier to loop through data, count values, find maximum or minimum values, and process large amounts of information.
