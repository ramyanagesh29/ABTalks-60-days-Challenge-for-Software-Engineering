# Optional Portfolio Website Outline

1. **Hero:** Name, role goal, brief introduction, GitHub and LinkedIn.
2. **Featured projects:** 3–4 projects with problem, features, stack, repository, and working demo.
3. **Skills:** Only skills you can confidently discuss.
4. **Learning journey:** Selected DSA and software engineering topics.
5. **Resume:** Link to a current PDF resume.
6. **Contact:** Professional email and profile links.

Keep the design mobile-friendly, accessible, fast, and easy to scan. Avoid unsubstantiated skill-rating bars.
