# GitHub Repository Polish Checklist

For each featured project:
- [ ] Clear repository name and one-sentence description.
- [ ] README includes overview, features, tech stack, setup, environment variables, screenshots, and limitations.
- [ ] Add appropriate `.gitignore`.
- [ ] Remove API keys, passwords, tokens, and secrets.
- [ ] Use `.env.example` with placeholders if environment variables are needed.
- [ ] Verify installation instructions from a clean clone.
- [ ] Document API endpoints where applicable.
- [ ] Add screenshots or a demo GIF if useful.
- [ ] Add a deployment link only if it works publicly.
- [ ] Use meaningful commit messages.
- [ ] Keep claims consistent with the actual code.
- [ ] Pin your strongest 3–4 repositories on GitHub.

Suggested descriptions:
- GD Prep Coach: AI-assisted group discussion practice web application.
- Inventory Management System: Full-stack product and stock tracking application.
- ProjectFlow: MERN project-management app with protected routes and dashboard summaries.
- Smart Spam Detector: Streamlit SMS classification prototype using TF-IDF and Naive Bayes.
