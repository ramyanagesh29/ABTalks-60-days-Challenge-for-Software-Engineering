For p=2, q=8:

Therefore LCA = 6.

For p=2, q=5:
Both values are smaller than 6, so move left.
At 2, one target equals the current node.
Therefore LCA = 2.

BST rule:
Both smaller -> LEFT
Both larger -> RIGHT
Otherwise -> CURRENT NODE is LCA
